# إدارة الإنترنت - منية البناء

مشروع ويب يعرض خدمات ومعلومات حول إدارة الإنترنت والخدمات الرقمية.

## الميزات
- تصميم حديث وأنيق باستخدام Bootstrap.
- تأثيرات حركة سلسة باستخدام Animate.css.
- نموذج اتصال يعمل باستخدام EmailJS.
- تصميم متجاوب على جميع الأجهزة.

## كيفية الاستخدام
1. استنسخ المشروع إلى جهازك.
2. افتح `index.html` في متصفحك.
3. قم بتعديل المعلومات حسب الحاجة.

## المتطلبات
- اتصال بالإنترنت لتحميل مكتبات CSS و JavaScript.
- حساب على EmailJS لاستخدام نموذج الاتصال.

## الترخيص
